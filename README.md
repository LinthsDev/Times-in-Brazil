# 📰 Times In Brazil

O **Times In Brazil** é um portal de notícias web simples desenvolvido em HTML5 e CSS3, focado em exibir matérias jornalísticas e conteúdos multimídia com navegação entre diferentes seções e páginas temáticas.

---

## 📁 Estrutura do Projeto

```text
Times In Brazil/
├── assets/
│   ├── audio/       # Arquivos de áudio
│   ├── css/         # Estilos da aplicação (home.css)
│   ├── images/      # Imagens do portal
│   └── videos/      # Vídeos das matérias
├── canada.html      # Página sobre o Canadá
├── france.html      # Página sobre a França
├── index.html       # Página principal (Home)
├── page-2.html      # Segunda página de notícias
├── spain.html       # Página sobre a Espanha
└── usa.html         # Página sobre os Estados Unidos
🚀 Funcionalidades
Navegação Interativa: Menu lateral/superior com links para diferentes páginas do portal.

Exibição de Mídias: Suporte a exibição de vídeos e imagens direto nas matérias.

Conteúdo Expansível: Utilização da tag <details> para ocultar/exibir conteúdos complementares.

Design Modular: Separação clara de estilos CSS e assets em pastas organizadas.

🛠️ Tecnologias Utilizadas
HTML5: Estruturação semântica do conteúdo (<header>, <main>, <nav>, <section>, <footer>).

CSS3: Estilização visual dos elementos (assets/css/home.css).

🔧 Como Executar o Projeto
Clone ou baixe este repositório para o seu computador.

Abra a pasta do projeto no seu editor de código (ex: VS Code).

Abra o arquivo index.html em qualquer navegador web (ou utilize a extensão Live Server no VS Code).
